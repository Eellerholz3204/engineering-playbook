# Entity Workspace Pattern

The candidate workspace name is retained as a familiar example of the broader entity-workspace pattern.

An entity workspace centers operational work on one primary business entity. It may surface identity, evidence, processing status, profile views, history, evaluations, workflow status, related contexts, and authorized commands.

It does not own authoritative entity data, source evidence, evaluation policy, ranking, or final decisions.

Projects should rename the concrete workspace to match their domain while preserving these boundaries.
